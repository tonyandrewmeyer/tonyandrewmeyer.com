These are the tools that I regularly use, and which I would obviously recommend:
**Coding**

- [Python](http://python.org/) is my preferred programming language.
- [Mark Hammond's pywin32 extensions for Python](http://starship.python.net/crew/mhammond/) are invaluable, especially the PythonWin IDE.
- [py2exe](http://py2exe.sf.net/) is perfect for creating Python executables.
- [Inno Setup](http://www.jrsoftware.org/) is a great, free, installer builder for Windows.
- [SpamBayes](http://spambayes.org/) is the best spam filter there is .
- [Kodos](http://kodos.sourceforge.net/) is fantastic for testing/creating regular expressions (particularly ones to be used in Python). [[more]](http://www.massey.ac.nz/%7Etameyer/writing/tools.html#kodos)
- [wxPython](http://www.wxpython.org/) is my preferred Python GUI development library.

**Editors**
I've given up on the editors I was using, and for the moment, I'm just using [PythonWin](http://starship.python.net/crew/mhammond/) for everything. The search may resume...
**PhD Research**

- [OpenCV](http://www.intel.com/research/mrl/research/opencv/) is a pretty good Computer Vision library. The capturing code isn't very good, though, and don't bother if you need to capture from multiple video sources (you can still use the processing code though).
- [VideoCapture](http://videocapture.sourceforge.net/) uses DirectX to capture from a video camera, and provides some Python wrappers for this.
- [Gamebots](http://gamebots.sourceforge.net/) is an excellent mod for Unreal Tournament that lets you control/monitor bots via a socket connection.
- [Festival](http://www.cstr.ed.ac.uk/projects/festival/) for free, open source, cross platform, speech synthesis.
- [Sphinx](http://www.speech.cs.cmu.edu/sphinx/) for free, open source, cross platform, speech recognition.

**General** 

- [Microsoft's PowerToys](http://www.microsoft.com/windowsxp/pro/downloads/powertoys.asp) are invaluable, particularly the calculator, the alt-Tab replacement, and the TweakUI control panel.
- [Cygwin](http://cygwin.com/) is necessary for any Windows user that doesn't have a *nix install handy.
- Alas, smspop (a very handy and cheap way to txt) is dead. I have not found a good replacement yet (I'm using [ipipi](http://www.ipipi.com) for the moment) - if anyone knows of one, let me know! I am not interested in something that involves opening a web browser and going to a site and logging in before txting. Txts should be less than 20c, otherwise I could just use my phone.
- [TortoiseCVS](http://www.tortoisecvs.org/) is a replacement for WinCVS, and is much more handy.
- [WinMerge](http://winmerge.sourceforge.net/) is the best GUI diff editor that I've found.
- [MinGW](http://mingw.org/) is the compiler I use when not using Cygwin.
- [Martin's gcc/JFE package](http://www.massey.ac.nz/%7Emjjohnso/) is a conveniently small C/C++ IDE setup.
- The [Google Deskbar](http://toolbar.google.com/deskbar/index.html) Handy searching. Get the [Desktop Search](http://desktop.google.com/) to go with it.
- [MCL](http://www.mlin.net/MCL.shtml) is a nifty little command line utility, rather like the Start->Run system, but better.
- [Firefox](http://www.mozilla.org/firefox) - what you should be using to view this page.
