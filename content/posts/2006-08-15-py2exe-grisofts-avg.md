As of today, [Grisoft's AVG](http://grisoft.com/) anti-virus software is reporting any Windows (non-console) application built using [py2exe](http://www.py2exe.org/) (maybe just with [Python](http://python.org/) [2.4](http://www.python.org/download/releases/2.4/)?) as a virus.
If AVG is suddenly reporting an application you have used for a long time as a virus, **don't believe it**. Unfortunately, unless you disabled AVG, it will probably have already deleted (moved to the 'vault') the application.
I (along with many others) have reported this to AVG, but please do so as well. They need to learn to be more careful when detecting real viruses.
[eWido's anti-virus/anti-spyware software](http://www.ewido.net/en/) had the same problem a couple of weeks ago (by the 24th of July they had corrected the error). I had hoped for better from AVG.
(This is all the fault of the [Backdoor.Rajump](http://www.symantec.com/avcenter/venc/data/backdoor.rajump.html) [Trojan](http://en.wikipedia.org/wiki/Trojan_horse_%28computing%29)).
