When [iTunes](http://www.apple.com/itunes) 7 was released, it was packaged with Apple's software update program for Windows (looking vaguely like software update for [OS X](http://www.apple.com/macosx)). It seemed like this meant that we could finally stop downloading a complete [QuickTime](http://www.apple.com/quicktime) + iTunes install each time there was a tiny update to iTunes.
However, iTunes 7.0.1 is out, and while iTunes can find it, Software Update can't. So what is this application for?
